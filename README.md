Entry for the [How Many Tabs Do You Have Open?](https://make.fun/competitions/u-danu-how-many-tabs-do-you-have-open-d86e783d) competition on make.fun.

## What it does

`main.py` (Python 3.13, stdlib only, deterministic — no network, no clock,
no randomness) writes a single number, digits only, to `/output/entry.txt`:
my honest count of open browser tabs.

**997** — years of "I'll read that later" across several browser windows and
profiles: research, docs, half-finished articles, things opened to check once
and never closed. Not a round number, not a stunt: a hoarder's real, lived-in
total, one tab short of a thousand.

## Run

```sh
python3 main.py
cat /output/entry.txt   # 997
```
